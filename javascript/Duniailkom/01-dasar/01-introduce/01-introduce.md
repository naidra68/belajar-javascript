# Berkenalan dengan Javascript

Javascript merupakan bahasa pemrograman yang bisa digunakan dengan HTML.

## Pengertian Javascript

Javascript adalah bahasa pemrograman web yang digunakan untuk memanipulasi element HTML dan membuat interaksi.

Contoh :

- tombol `'di klik'` >> muncul apa.
- gambar berganti-ganti
- mengubah warna otomatis

Javascript menambahkan aspek "interaktif" ke dalam HTML dan CSS.

Contoh :

- `<h1>` 'di klik' >> tampil artikel dengan 10 paragraf.
- gambar `'di klik'` >> bisa ganti componen css-nya.

Javascript termasuk kelompok bahasa pemrograman web berbasis client. Maksudnya, Javascript di proses dalam web browser yang sama seperti kode HTML dan CSS.

Javascript disebut sebagai <b>bahasa pemrograman tingkat tinggi</b> atau high-level programming language karena kode-nya sudah mirip dengan bahasa inggris sehari-hari.

Javascript diproses secara <b>interpreted</b> dimana sebuah variabel tidak perlu ditetapkan tipe data nya, karena setiap variabel dapat diisi oleh tipe data apapun. Hal ini cukup berbeda dengan bahasa pemrograman sepuh macam C, C++, dan Java.

Jika pernah belajar salah satu dari 3 bahasa sepuh tersebut maka akan terlihat perbedaan ketika belajar Javascript, jika tidak? maka tidak perlu khawatir tentang hal itu.

## Javascript dan DOM

Jika belajar javascript maka harus paham mengenai DOM, javascript adalah bahasa pemrograman, sedangkan DOM merupakan HTML object yang dapat dimanipulasi seperti teks, gambar, form, tombol dan lain-lain.

Simple nya gini, agar Javascript bisa berjalan ke dalam tag HTML, maka perlu yang nama-nya DOM. Jika tidak, maka javascript akan berjalan di belakang Web browser yang bisa dilihat pada console.

Untuk awalan, sebaiknya belajar Javascript dengan fokus pada sisi programming-nya seperti variabel, tipe data, operator, kondisi, perulangan, dan function.

Jika sudah memahami semua itu, maka selanjutnya baru belajar DOM untuk mengimplementasikan semua nya pada Object HTML. Ketika belajar pertama kali javascript sisi programming.

Dijamin akan bosan karena harus berurusan dengan console dan tidak mendapatkan tampilan yang diinginkan seperti website-website pro diluar sana, namun seru-nya akan kelihatan jika berurusan dengan DOM.

Untuk memanipulasi DOM, perlu struktur pemahaman Javascript yang kuat, meskipun bosan namun paksakan saja karena ini penting untuk di ingat.
