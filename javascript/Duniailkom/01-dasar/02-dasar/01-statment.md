# Statment

Statment merupakan sebutan untuk sebuah baris perintah atau banyak baris perintah. 

berikut contoh penulisan statment pada Javascript :

```js
console.log('Hello World');
var a = 1;
var b = "wok";
var c = 3.14;
let hidup = document.getElementById("HIDUP [insert text here]");
const elementsBox = document.getElementByClassName("box");
```

Tidak perlu dipikirkan tentang kode diatas jika bingung, itu hanyalah contoh penulisan statment dalam javascript, kita akan mempelajari semua kode diatas jika sudah memasuki halaman variabel dan DOM Javascript.
