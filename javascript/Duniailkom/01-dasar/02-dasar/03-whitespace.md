# Whitespace

Whitespace berarti karakter koosng seperti spasi,tab, dan new line. Whitespace secara umum diabaikan oleh javscript dan tidak menampilkan hasil apapun.

Jadi penulisan javascript menggunakan whitespace ataupun tidak maka itu dianggap valid. Penggunaan whitespace untuk tampilan kode yang mudah dibaca oleh sesama programmer.

Berikut contoh penerapan-nya

```js
var a = "Hello World"; console.log(a); var b = "Selamat Datang";
```

Itu sama saja dengan menulis berikut :

```js
var a = "Hello World";
console.log(a);
var b = "Selamat Datang";
```

> Penambahan whitespace tidak mempengaruhi fungsi kode javascript, namun dapat memperbesar ukuran file Javascript. Ketika kode javascript sudah kompleks maka akan besar juga ukuran file tersebut. Untuk meminimalisir ukuran file dapat menggunakan aplikasi semacam <i><b>javascript compress</i></b> atau <i><b>minifier</i></b>

> Pembahasan mendalam mengenai javascript minifer akan dijelaskan pada halaman terpisah.
