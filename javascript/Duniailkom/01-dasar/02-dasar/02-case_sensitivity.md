# Case Sensitivity

Javascript bersifat case sensitif, dimana huruf besar dan huruf kecil dianggap berbeda. Salah penulisan sering terjadi ketika baru pertama kali mencoba Javascript, apalagi dengan perintah javascript yang panjang penulisan-nya seperti `document.getElementById()`.

Penulisan fungsi tersebut harus ditulis sesuai agar berfungsi, penulisan yang tidak tepat akan menyebabkan error. Aturan ini juga berlaku pada variabel dan keyword. Jadi semua unsur didalam javascript bersifat case sensitivity.


🟢 Benar
```js
document.getElementById();
```

🔴 Salah

```js
document.GetElementById();
```
