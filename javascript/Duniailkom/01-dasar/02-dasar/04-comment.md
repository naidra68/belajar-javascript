# Komentar

Komentar ini selalu ada pada bahasa pemrograman, bahkan bahasa markup HTML dan bahasa style CSS memiliki komentar masing-masing. 

Sama seperti bahasa pemrograman lain, baris komentar ini tidak akan dieksekusi oleh Javascript. Fungsinya hanya sebagai komentar pada kode kita apabila suatu saat kita lupa fungsi terhadap kode sendiri.

berikut contoh penerapan-nya

```js
// Ini merupakan komentar Javascript
// Baris ini tidak akan pernah diproses oleh Javascript
/*
    Untuk membuat multiple komentar
    kita perlu gunakan garing bintang untuk pembuka
    dan bintang garing untuk penutup 
*/
// Created by Naidra68
```

Komentar ini penting untuk pengingat kita serta juga pengingat orang lain, jika kita sudah bekerja tim atau membagikan kode kita secara online. Maka komentar ini sebagai pedoman tim atau orang yang mengambil kode kita. Simple nya kayak dokumentasi kode lah ya.

Fungsi komentar selain dokumentasi juga dapat menonaktifkan kode javascript. Apabila kita pengen debugging javascript atau ingin agar kode tersebut tidak di jalankan, alih-alih menghapus kode tersebut, kita bisa nonaktifkan sementara kode-nya, siapa tau kita butuh lagi kode tersebut.

berikut contoh penerapan-nya

```js
// var a = "Joe Kou Wie";
var a = "Pra Bou Wou";
```
